> **① 서브쿼리란 (Subquery)**

****\- 서브쿼리(Subquery)란 SELECT문 안에 또다시 SELECT문을 사용하는 SQL문입니다.

\- 서브쿼리는 위치에 따라 명칭이 다릅니다.

1) FROM절에 사용하는 인라인뷰(Inline View)

2) SELECT문에 Subquery를 사용하는 스칼라 서브쿼리(Scala Subquery)

3) WEHRE구에 SELECT문을 사용하면 서브쿼리(Subquery)라고 합니다.

> **② 서브쿼리 형태**

**1) 서브쿼리(Subquery)******

\- 일반적으로 WHERE구에 SELECT문을 사용한 서브쿼리입니다.

SELECT \*

   FROM EMP

WHERE DEPTNO =  (

                                      SELECT DEPTNO

                                         FROM DEPT

                                      WHERE DEPTNO = 10

                                    );

![](/images/tistory/54/2.png)

**2) 인라인 뷰(Inline View)******

\- FROM 절에 사용하는 서브쿼리입니다.

SELECT \*

   FROM (

                  SELECT ROWNUM NUM, ENAME

                     FROM EMP

                )

WHERE NUM &lt; 5;

![](/images/tistory/54/3.png)

**3) 스칼라 서브쿼리(Scala Subquery)******

\- SELECT문에 사용하는 서브쿼리입니다.

\- 스칼라 서브쿼리는 반드시 한 행과 한 칼럼만 반환하는 서브쿼리입니다.

\- 만약 여러 행이 반환되면 오류가 발생합니다.

SELECT ENAME AS "이름"

               , SAL AS "급여"

               , (

                      SELECT AVG(SAL)

                       FROM EMP

                  ) AS "평균급여"

   FROM EMP

WHERE EMPNO = 7698;

![](/images/tistory/54/4.png)

> **③ 단일 행 서브쿼리와 다중 행 서브쿼리**

****\- 서브쿼리(Subquery)는 반환하는 행 수가 한 개인 것과, 여러개 인 것에 따라서 단일행 서브쿼리와 멀티 행 서브쿼리로 분류합니다.

\- 단일 행 서브쿼리는 단 하나의 행만 반환합니다. ( 비교연산자 =, &lt;, &lt;=, >=, &lt;>를 사용합니다)

\- 다중 행 서브쿼리는 여러 개의 행을 반환합니다. (IN, ANY, ALL, EXISTS를 사용합니다.)

**1) 다중행 비교연산자 IN 예제**

\- EMP 테이블에서 SAL이 1500 초과인 사원번호를 반환하고, 반환된 사원번호와 메인쿼리에 있는 사원번호와 비교하여 같은 것을 조회하라.

SELECT ENAME, DNAME, SAL

   FROM EMP,DEPT

WHERE EMP.DEPTNO = DEPT.DEPTNO

      AND EMP.EMPNO IN (

                                            SELECT EMPNO

                                               FROM EMP

                                            WHERE SAL > 1500

                                           );

**2) 다중행 비교연산자 ALL 예제**

\- DEPTNO가 20, 30 둘중 하나보다 작거나 같으면 조회

SELECT \*

   FROM EMP

WHERE DEPTNO &lt;= ALL (20, 30);

![](/images/tistory/54/5.png)

**3) 다중행 비교연산자 EXISTS 예제**

\- 직원 중에서 SAL이 2000이상이 있으면 참이 반환되고, 없으면 거짓이 반환된다.

SELECT ENAME, DNAME, SAL

    FROM EMP, DEPT

  WHERE EMP.DEPTNO = DEPT.DEPTNO

        AND EXISTS  (

                                  SELECT 1

                                      FROM EMP

                                   WHERE SAL > 2000

                                );

![](/images/tistory/54/6.png)

> **④ 스칼라 서브쿼리 (Scala Subquery)**

****\- 스칼라 서브쿼리는 반드시 한 행과 한 칼럼만 반환하는 서브쿼리입니다.

\- 만약 여러 행이 반환될 경우, 오류가 발생합니다.

**예제)**

SELECT ENAME

               , SAL

               , (

                    SELECT AVG(SAL)

                       FROM EMP

                 )

     FROM EMP

   WHERE EMPNO = 7839;
