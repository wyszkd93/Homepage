> **※ 조인(join) 이란?**
> 
> 
> 
> JOIN문은 두개 이상의 테이블을 조회한 결과를 결합하여 하나의 결과를 얻고 싶을때
> 
> 사용하는 구문입니다.

* * *

> **① EQUI (등가) 조인 - 교집합**

**- 조인은 여러개의 릴레이션을 사용해서 새로운 릴레이션을 만드는 과정입니다.**

**1) EQUI (등가) 조인**

**\- EQUI 등가 조인은 두개의 테이블 간에 일치하는 것을 조인합니다.**

**\- EQUI 조인은 가장 많이 사용되는 조인 방법으로 조인 대상이 되는 두테이블에서 공통적으로 존재하는 칼럼의 값이 일치하는 행을 연결하여 결과를 생성합니다.**

**\- EQUI 조인은 "="를 사용하여 두 개의 테이블을 연결합니다.**

![](/images/tistory/51/3.jpg)

**예시) EMP 테이블의 DEPTNO와 DEPT테이블의 DEPTNO가 같은것을 사용하여 JOIN 하라**

SELECT \*

   FROM EMP,DEPT

WHERE EMP.DEPTNO = DEPT.DEPTNO ;

![](/images/tistory/51/4.png)

**예시2) EMP 테이블과 DEPT 테이블의 DEPTNO가 같은 것을 사용하여 JOIN 후 EMP의 ENAME이 "M"으로 시작하는 데이터를**

**ENAME오름 차순으로 정렬하라.**

SELECT \*

   FROM EMP,DEPT

WHERE EMP.DEPTNO = DEPT.DEPTNO

      AND EMP.ENAME LIKE 'M%'

ORDER BY ENAME;

![](/images/tistory/51/5.png)

**2) INNER JOIN**

**\- EQUI 조인과 마찬가지로 ISO 표준 SQL로 INNER JOIN이 있습니다.**

**\- INNER JOIN 은 ON을 사용하여 테이블을 연결합니다.**

**예시) EMP 테이블의 DEPTNO와 DEPT테이블의 DEPTNO가 같은것을 사용하여 JOIN 하라**

SELECT \*

   FROM EMP INNER JOIN DEPT

        ON EMP.DEPTNO = DEPT.DEPTNO ;

![](/images/tistory/51/6.png)

**예시2) EMP 테이블과 DEPT 테이블의 DEPTNO가 같은 것을 사용하여 JOIN 후 EMP의 ENAME이 "M"으로 시작하는 데이터를**

**ENAME오름 차순으로 정렬하라.**

SELECT \*

  FROM EMP INNER JOIN DEPT

       ON EMP.DEPTNO = DEPT.DEPTNO

     AND EMP.ENAME LIKE 'M%'

ORDER BY ENAME;

![](/images/tistory/51/7.png)

> **② NON-EQUI 조인 (비등가 조인)**

**- Non-EQUI 조인은 두개의 테이블 간에 조인하는 경우 "="를 사용하지않고 ">","&lt;",">=","&lt;=" 등을 사용합니다.**

**\- 즉, Non-EQUI 조인은 정확하게 일치하지 않는 것을 조인합니다.**

**실습01) SALGRADE 등급 테이블 만들고, 데이터를 삽입합니다.**

> **※ 구조**
> 
> 
> 
> \- 급여의 등급은 총 5등급으로 나누어져 있습니다.
> 
> \- 1등급은 급여가 700 ~ 1200 / 2등급은 급여가 1201 ~ 1400 / 3등급은 급여가 1401 ~ 2000 / 4등급은 2001 ~ 3000
> 
> 5등급은 급여가 3001 ~ 9999 사이

CREATE TABLE SALGRADE

  ( GRADE NUMBER (3,0) NOT NULL,

      LOSAL NUMBER(5,0) NOT NULL,  
      HISAL NUMBER(5,0) NOT NULL

);

INSERT INTO SALGRADE (GRADE, LOSAL, HISAL) VALUES (1, 700, 1200);

INSERT INTO SALGRADE (GRADE, LOSAL, HISAL) VALUES (2, 1201, 1400);

INSERT INTO SALGRADE (GRADE, LOSAL, HISAL) VALUES (3, 1401, 2000);

INSERT INTO SALGRADE (GRADE, LOSAL, HISAL) VALUES (4, 2001, 3000);

INSERT INTO SALGRADE (GRADE, LOSAL, HISAL) VALUES (5, 3001, 9999);

SELECT \*

FROM SALGRADE;

![](/images/tistory/51/8.png)

**실습02) EMP 테이블의 SAL(급여)에 맞춰 SALGRADE의 등급을 확인해보는 예제**

SELECT E.ENAME, E.SAL, E.JOB, S.GRADE

   FROM EMP E, SALGRADE S

WHERE E.SAL >= S.LOSAL

      AND E.SAL &lt;= S.HISAL;

![](/images/tistory/51/9.png)

**실습03) 이름, 부서명, 급여등급을 출력하기위해 emp,dept,salgrade 3개의 테이블 조인하여 출력하기**

SELECT E.ENAME, D.DNAME, S.GRADE

    FROM EMP E, DEPT D, SALGRADE S

 WHERE E.DEPTNO = D.DEPTNO

       AND E.SAL BETWEEN S.LOSAL

       AND S.HISAL ORDER BY GRADE;

![](/images/tistory/51/10.png)

> **③ OUTER JOIN**

**- OUTER JOIN은 두개의 테이블간의 교집합을 조회하고, 한쪽 테이블에만 있는 데이터도 포함시켜서 조회합니다.**

**\- DEPT 테이블과 EMP테이블을 OUTER JOIN 하면 DEPTNO가 같은 것을 조회하고 DEP테이블에만 있는 DEPTNO도 조회합니다.**

**\- 이때, 왼쪽 테이블에만 있는 행도 포함하면 LEFT OUTER JOIN 이고 오른쪽 테이블의 행만 포함시키면 RIGTH OUTER JOIN 이라고합 니다.**

**\- FULL OUTER JOIN 은 LEFT OUTER JOIN과 RIGHT OUTER JOIN 모두를 하는 것 입니다.**

**\- ORACLE 데이터베이스에서는 OUTER JOIN을할때 "(+)" 기호를 사용할 수 있습니다.**

**예시)**

SELECT \*

   FROM DEPT, EMP

WHERE EMP.DEPTNO (+)= DEPT.DEPTNO ;

![](/images/tistory/51/11.png)

**1) LEFT OUTER JOIN**

**\-LEFT OUTER JOIN은 두 개의 테이블에서 같은 것을 조회하고 왼쪽 테이블에만 있는 것을 포함하여 조회합니다.**

![](/images/tistory/51/12.jpg)

SELECT \*

   FROM DEPT LEFT OUTER JOIN EMP

        ON DEPT.DEPTNO = EMP.DEPTNO ;

![](/images/tistory/51/13.png)

**2) RIGHT OUTER JOIN**

**\-RIGHT OUTER JOIN은 두 개의 테이블에서 같은 것을 조회하고 오른쪽 테이블에만 있는 것을 포함하여 조회합니다.**

![](/images/tistory/51/14.jpg)

SELECT \*

   FROM DEPT RIGHT OUTER JOIN EMP

        ON DEPT.DEPTNO = EMP.DEPTNO ;

![](/images/tistory/51/15.png)

**3) FULL OUTER JOIN**

**\- LEFT, RIGHT 모든 데이터를 읽어 JOIN 하여 결과를 출력합니다.**

![](/images/tistory/51/16.jpg)

SELECT \*

   FROM DEPT FULL OUTER JOIN EMP

        ON DEPT.DEPTNO = EMP.DEPTNO ;

![](/images/tistory/51/17.png)

> **④ CROSS JOIN**

**- CROSS JOIN은 조인 조건구 없이 2개의 테이블을 하나로 조인합니다.**

**\- 조인구가 없기 때문에 카테시안 곱이 발생합니다.**

**\- 예를 들면, 행이 14개 있는 테이블과 4개 있는 테이블을 조인하면 56개의 행이 조회됩니다.**

**\- CROSS JOIN은 FROM 절에 CROSS JOIN구를 사용하면됩니다.**

SELECT \*

   FROM EMP CROSS JOIN DEPT;

![](/images/tistory/51/18.png)

**\- EMP테이블에는 총 14건의 데이터가, DEPT 테이블에는 총 4건의 데이터가 있습니다.**

**\- 총 조인은 14 \* 4 = 56 건의 데이터가 나옵니다.**
