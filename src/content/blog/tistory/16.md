> **Redo Log file 조회**

```delphi
SQL> SELECT a.group#
          , a.member
          , b.bytes
          , b.status
          , b.sequence#
       FROM v$logfile a, v$log b
      WHERE a.group#=b.group#
      ORDER BY 1;
```

\- GROUP # : 그룹번호

\- MEMBER : 멤버 파일의 경로 및 파일명

\- BYTES : 멤버 파일의 크기

\- STATUS : 그룹의 상태

\> 강제로 logswitch 발생 시킨 후 확인

```delphi
SQL> alter system switch logfile;

System altered.
```

![](/images/tistory/16/2.png)

\- Active : Redo가 switch된 상태로 checkpoint가 발생하여 쌓인 기록들을 DatabufferCache(Memory)에 있는 실제 내용을 Datafile에 기록중

\- Current : 현재 변경된 기록들이 쌓이고 있는 상태의 Redo

\- Inacitve : 모든 작업이 다 끝나고 휴지 상태

\> 강제로 Check point 발생 후 확인

```delphi
SQL> ALTER SYSTEM CHECKPOINT;

System altered.
```
