> **① 내장형 함수란?**

\- 내장함수란 CREATE FUNCTION 기능을 사용해 만든 함수가 아닌 오라클 자체적으로 제공하는 함수입니다.

\- 모든 데이터베이스는 SQL에서 사용할 수 잇는 내장형 함수를 가지고있습니다.

\- 내장형 함수는 데이터베이스 관리시스템 벤더별로 약간의 차이가 있지만, 거의 비슷한 방법으로 사용이 가능합니다.

\- 내장형 함수로는 형변환함수/문자열/숫자형 함수/날자형 함수가 있습니다.

* * *

> **② DUAL 테이블**

\- DUAL 테이블은 Oracle 데이터베이스에 의해서 자동으로 생성되는 테이블입니다.

\- Oracle 데이터베이스 사용자가 임시로 사용할 수 잇는 테이블로 내장형 함수를 실행할 때도 사용할 수 있습니다.

\- Oracle 데이터베이스의 모든 사용자가 사용할 수 있습니다.

\- Oracle은 기본적으노 DUAL테이블이라는 Dummy테이블이 존재합니다.

예시01 ) SELECT 1+1 FROM DUAL;

> **※ ASCII 란**
> 
> 
> 
> \- ASCII 함수는 문자에 대한 ASCII코드 값을 알려줍니다. ASCII 코드는 대문자A 기준으로 A(65), B(66), C(67) 등의 값입니다.
> 
> \- ASCII (아스키) 코드란 미국 국립표준 협회에서 표준화한 정보교환용 7비트 부호체계입니다.
> 
> \- 아스키는 컴퓨터와 통신 장비를 비롯한 문자를 사용하는 많은 장치에서 사용되며,대부분의 문자 인코딩이 아스키에 기초를 두고 있다. 아스키는 33개의 출력 불가능한 제어 문자들과 공백을 비롯한 95개의 출력 가능한 문자들로 000(0x00)부터 127(0x7F)까지 총 128개로 이루어집니다.

**예제01) ASCII, SUBSTR, CONCAT**

```sql
SELECT ASCII('a'), SUBSTR('ABCDEF', 3, 2), CONCAT('A', 'BC')
FROM DUAL;
```
