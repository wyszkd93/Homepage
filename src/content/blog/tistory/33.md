> **실행 방법** 

  > shell 수행만 진행하며, GUI환경에서 진행하는 것보다 시간이 좀 오래걸림

```shell
ora12c@ol79rac1[ORA12C]:/u01/app/oracle/admin/ORA12C/scripts$ sh ORA12C.sh
```

```shell
ORA12C.sh 내용

#!/bin/sh

OLD_UMASK=`umask`
umask 0027
mkdir -p /u01/app/oracle
mkdir -p /u01/app/oracle/12.2.0.1/dbhome_1/dbs
mkdir -p /u01/app/oracle/admin/ORA12C/adump
mkdir -p /u01/app/oracle/admin/ORA12C/dpdump
mkdir -p /u01/app/oracle/admin/ORA12C/pfile
mkdir -p /u01/app/oracle/audit
mkdir -p /u01/app/oracle/cfgtoollogs/dbca/ORA12C
mkdir -p /u01/app/oracle/oradata/ORA12C
umask ${OLD_UMASK}
PERL5LIB=$ORACLE_HOME/rdbms/admin:$PERL5LIB; export PERL5LIB
ORACLE_SID=ORA12C; export ORACLE_SID
PATH=$ORACLE_HOME/bin:$ORACLE_HOME/perl/bin:$PATH; export PATH
echo You should Add this entry in the /etc/oratab: ORA12C:/u01/app/oracle/12.2.0.1/dbhome_1:Y
/u01/app/oracle/12.2.0.1/dbhome_1/bin/sqlplus /nolog @/u01/app/oracle/admin/ORA12C/scripts/ORA12C.sql
```

```shell
ORA12C.sql 내용

set verify off
ACCEPT sysPassword CHAR PROMPT 'Enter new password for SYS: ' HIDE
```
