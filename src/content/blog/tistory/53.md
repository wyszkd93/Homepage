> **① 계층형조회란? (Connect by)**

****\- 계층형 조회는 Oracle 데이터베이스에서 지원하는것으로 계층형으로 데이터를 조회할 수 있습니다.

\- 부장->차장->과장->대리->사원 순으로 트리 형태의 구조를 위에서 아래로 탐색하면서 조회하는 것입니다.

\- 역방향도 물론 가능합니다.

> **② CONNECT BY 구조**

\- CONNECT BY는 아래 3개의 구문으로 구성됩니다.

\- START WITH는 가장 처음에 데이터를 거르는 플랜을 타게 되고, 이 컬럼에는 인덱스가 걸려있어야 성능을 보장받습니다.

\- CONNECT BY 절의 결과에는 LEVEL이라는 컬럼이 있으며, 이는 계층의 깊이를 이야기합니다.

\- CONNECT BY는 트리 형태의 구조로 질의를 수행하는 것으로 START WITH구는 시작 조건을 의미하고, CONNECT BY PRIOR은 조인 조건입니다. ROOT노드로 부터 하위 노드의 질의를 실행합니다.

> **④ CONNECT BY 사용하기**

**\* 먼저 EMP테이블 데이터를 확인해봅니다.**

SELECT \*

   FROM EMP;

![](/images/tistory/53/3.png)

EMPNO는 직번이고, MGR은 관리자의 직번입니다.

1번 로우의 KING (EMPNO 7839) 는 회장이라 관리자란이 비어있습니다.

2번 로우의 BLAKE(EMPNO 7698)은 상사직번이 7839(KING)으로 회장님이 직접 관리하는 직원입니다.

14번 로우의 MILLER(EMPNO 7934)는 상사직번이 7782으로 CLARK이 관리자입니다.

**예제1) EMP의 계층구조를 보기좋게 만들어주세요.**

SELECT LPAD(' ',(LEVEL-1)\*5) || ENAME

   FROM EMP

  START WITH MGR IS NULL

 CONNECT BY PRIOR EMPNO = MGR;

![](/images/tistory/53/4.png)

> \*코드분석
> 
> 
> 
> **SELECT LPAD(' ',(LEVEL-1)\*5)||ENAME** \-- LPAD를 이용한 공백만들기
> 
> **FROM EMP** \-- EMP테이블에서
> 
> **START WITH MGR IS NULL** -- MGR이 NULL인 KING을 시작행으로 가져오기
> 
> **CONNECT BY PRIOR EMPNO = MGR;** \-- 이전행의 EMPNO와 현재행의 MGR이 같은행을 가져오기

**예제2) EMP 의 최대 계층 수를 구하여라.**

SELECT MAX(LEVEL)

   FROM EMP

  START WITH MGR IS NULL

CONNECT BY PRIOR EMPNO = MGR;

![](/images/tistory/53/5.png)

> \*코드분석
> 
> 
> 
> **SELECT MAX(LEVEL)** \-- LEVEL에는 계층값을 가지고 잇습니다. MAX(LEVEL)을 사용하여 최대 계층 수를 구할 수 있습니다.
> 
> **FROM EMP**
> 
> **START WITH MGR IS NULL**
> 
> **CONNECT BY PRIOR EMPNO = MGR;**

**예제3) LPAD 자세히 알아보기**

SELECT LEVEL, EMPNO, MGR, ENAME

   FROM EMP

  START WITH MGR IS NULL

CONNECT BY PRIOR EMPNO = MGR;

![](/images/tistory/53/6.png)

> \*코드분석
> 
> 
> 
> \-- EMP테이블에서 LEVEL, EMPNO, MGR, ENAME을 호출하되
> 
> MGR이 NULL을 시작으로 이전행의 EMPNO와 현재행의 MGR이 같은행을 가져오기

SELECT LEVEL, LPAD(' ',4\*(LEVEL-1)) || EMPNO, MGR, ENAME

  FROM EMP

  START WITH MGR IS NULL

CONNECT BY PRIOR EMPNO = MGR;

![](/images/tistory/53/7.png)

> \*코드분석
> 
> **LPAD(' ',4\*(LEVEL-1)) || EMPNO**
> 
> ****
> 
> \- 계층형 조회 결과를 명확하게 보기 위해 LPAD 함수를 사용할 수 있습니다.
> 
> \- 위 예를 보면 4\*(LEVEL-1)이 있습니다. LEVEL 값이 ROOT이면 1이 됩니다 . 따라서 4\*(1-1)은 0이 됩니다.
> 
> 즉, ROOT일 때는 LPAD(' ',0)이므로 아무런 의미가 없습니다.
> 
> \- LEVEL 값이 2가되면 4\*(2-1)=4가 됩니다. LPAD(' ',4)이므로 왼쪽에 공백을 4칸 찍게 됩니다.
> 
> \- 결과적으로 LPAD는 트리 형태로 보기 위해서 사용한 것입니다.
> 
> \- LEVEL값이 ROOT에 1을 되돌리고, 그다음 자식은 2, 그 다음 자식은 3이 나오게 됩니다.

> **⑤ 오라클 순번,채번 CONNECT BY 활용하기**

**1) 1~10까지 연속된 숫자 조회하기**

SELECT LEVEL AS NO

   FROM DUAL

CONNECT BY LEVEL &lt;= 10;

![](/images/tistory/53/8.png)

**2) 2021년 1월부터 12월까지 출력하기**

SELECT '2020년 ' || LPAD(LEVEL, 2, 0) || '월' AS NO

   FROM DUAL

 CONNECT BY LEVEL &lt;= 12;

![](/images/tistory/53/9.png)
