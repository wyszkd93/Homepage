> **SELECT문 실행 순서**

\- SQL의 실행 순서는 결과로 조회된 데이터를 이해하는 데 아주 중요한 요소입니다.

\- SELECT문의 실행순서는 FROM - WHERE - GROUP BY - HAVING - SELECT - ORDER BY 순으로 실행됩니다.

```sql
SELECT ENAME
   FROM EMP
WHERE EMPNO = 7566
GROUP BY ENAME
HAVING COUNT(*) >= 1
ORDER BY ENAME;
```

(문제1 - 정답)

\- SELECT \* 은 모든 데이터를 조회합니다.

```sql
SELECT *
FROM EMP;
```

(문제2 - 정답)

\- FROM - WHERE - GROUP BY - HAVING - SELECT - ORDER BY

(문제3 - 정답)

\- COMMIT

\- TCL은 트랜잭션을 제어하는 명령어로 COMMIT과 ROLLBACK이 있습니다.

(문제4 - 정답)

```sql
ALTER TABLE EMP RENAME TO NEW_EMP;
```

(문제5 - 정답)

\- TRUNCATE 문은 테이블의 모든 데이터를 삭제하고 테이블 공간을 초기화합니다. (테이블자체는 삭제되지않음)

```sql
TRUNCATE TABLE EMP;
```
