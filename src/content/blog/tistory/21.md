> **Datafile 이동 작업**

> \- 사용중일 때 절대 이동시키면 안된다.  
> \- 신규 디스크로 이동시키는 작업 때 사용  
> \- 테이블 스페이스 오프라인 후 이동  
> \- 테이블 스페이스 오프라인이 안 될경우 DB 종료 후 마운트 상태에서 작업해야한다.

> **CASE A. 오프라인(Offline) 되는 테이블 스페이스의 경우 작업 과정**

> 1\. Tablespace Offline  
> 2\. 데이터 파일 옮길 대상 위치로 복사  
> 3\. Controlfile 내에 파일 위치 변경  
> 4\. Tablespace Online

> **CASE B. 오프라인(Offline) 안되는 테이블 스페이스의 경우 작업 과정**

> SYSTEM 테이블스페이스, UNDO 테이블 스페이스, DEFAULT TEMPORARY 테이블 스페이스  
>   
> 1\. DB shutdown  
> 2\. DB Mount  
> 3\. 데이터 파일 옮길 대상 위치로 복사  
> 4\. Controlfile 내에 파일 위치 변경  
> 5\. DB Open

> **Controlfile과 V$DATAFILE로 조회**

```shell
SQL> SELECT A.TABLESPACE_NAME,A.FILE_NAME,B.STATUS
  2  FROM DBA_DATA_FILES A, V$DATAFILE B
  3  WHERE A.FILE_NAME=B.NAME
  4  GROUP BY A.TABLESPACE_NAME,A.FILE_NAME,B.STATUS;

TABLESPACE_NAME    FILE_NAME                                                              STATUS
------------------ ---------------------------------------------------------------------- -------
SYSAUX             /ora_engine/oradata/ORA11G/datafile/o1_mf_sysaux_kxmy943p_.dbf         ONLINE
SYSTEM             /ora_engine/oradata/ORA11G/datafile/o1_mf_system_kxmy8ycp_.dbf         SYSTEM
UNDOTBS1           /ora_engine/oradata/ORA11G/datafile/o1_mf_undotbs1_kxmy9bnr_.dbf       ONLINE
USERS              /ora_engine/oradata/ORA11G/datafile/o1_mf_users_kxmy9ktb_.dbf          ONLINE
```

* * *

**\[CASE A. Tablespace Offline이 되는 경우 작업\]**

더보기

> **1\. Tablespace Offline**

```shell
SQL> ALTER TABLESPACE USERS OFFLINE;

Tablespace altered.
```

> **2\. OS명령어를 통해 복사 진행**

```shell
SQL> !cp -av /ora_engine/oradata/ORA11G/datafile/o1_mf_users_kxmy9ktb_.dbf /ora_data/normaltbs/user.dbf
‘/ora_engine/oradata/ORA11G/datafile/o1_mf_users_kxmy9ktb_.dbf’ -> ‘/ora_data/normaltbs/user01.dbf’
```

> **3\. Controlfile 내에 데이터파일 위치 변경**

```shell
SQL> ALTER TABLESPACE USERS RENAME
  2  DATAFILE '/ora_engine/oradata/ORA11G/datafile/o1_mf_users_kxmy9ktb_.dbf'
  3  TO '/ora_data/normaltbs/user01.dbf';
```

> **4\. Tablespace Online**

```shell
SQL> ALTER TABLESPACE USERS ONLINE;

Tablespace altered.
```

* * *

**\[CASE B. Tablespace Offline이 안되는 경우 작업\]**

더보기

> **1\. DB Shutdown**

```shell
SQL> shutdown immediate

Database closed.
Database dismounted.
ORACLE instance shut down.
```

> **2. DB Mount**

```shell
SQL> startup mount;

ORACLE instance started.
Total System Global Area 1269366784 bytes
Fixed Size                  2252864 bytes
Variable Size             822087616 bytes
Database Buffers          436207616 bytes
Redo Buffers                8818688 bytes
Database mounted.

SQL> select status
  2  from v$instance;

STATUS
------------
MOUNTED
```

> **3. OS명령어를 통해 복사 진행**

```shell
SQL> !cp -av /ora_engine/oradata/ORA11G/datafile/o1_mf_system_kxmy8ycp_.dbf /ora_data/normaltbs/system01.dbf
‘/ora_engine/oradata/ORA11G/datafile/o1_mf_system_kxmy8ycp_.dbf’ -> ‘/ora_data/normaltbs/system01.dbf’
-------------------------------------------------------------------------------------------------------------
SQL> !cp -av /ora_engine/oradata/ORA11G/datafile/o1_mf_undotbs1_kxmy9bnr_.dbf /ora_data/normaltbs/undo01.dbf
‘/ora_engine/oradata/ORA11G/datafile/o1_mf_undotbs1_kxmy9bnr_.dbf’ -> ‘/ora_data/normaltbs/undo01.dbf’
```

> **4\. Controlfile 내에 데이터파일 위치 변경**

```shell
SQL> ALTER DATABASE RENAME
  2  FILE '/ora_engine/oradata/ORA11G/datafile/o1_mf_system_kxmy8ycp_.dbf'
  3  TO '/ora_data/normaltbs/system01.dbf';

Database altered.
----------------------------------------------------------------------------
SQL> ALTER DATABASE RENAME
  2  FILE '/ora_engine/oradata/ORA11G/datafile/o1_mf_undotbs1_kxmy9bnr_.dbf'
  3  TO '/ora_data/normaltbs/undo01.dbf';

Database altered.
```

> **5\. DB Open**

```shell
SQL> ALTER DATABASE OPEN;

Database altered.
```
