> **① ROWNUM**

**\- ROWNUM은 오라클 데이터베이스의 SELECT문 결과에 대해 논리적인 일련번호를 부여합니다.**

**\- ROWNUM은 조회되는 행 수를 제한할 때 많이 사용됩니다.**

**\- ROWNUM은 화면에 데이터를 출력할 때 부여되는 논리적 순번입니다.**

**\- ROWNUM을 사용해서 페이지 단위 출력을 하기 위해서는 인라인뷰(Inline view)를 사용해야합니다.**

**\- 주로, 여러개의 결과를 출력하는 쿼리문을 실행 후 결과의 개수를 제한하여 가져오는데 사용됩니다.**

> **※인라인뷰(inline view)**
> 
> 
> 
> \- SELECT문의 FROM절 내부에 있는 또다른 SELECT문을 인라인뷰 라고 합니다.
> 
> 
> 
> ex) SELECT \* FROM // 메인쿼리
> 
> (SELECT \* FROM EMP) a; //서브쿼리

**기본테이블 EMP )**

![](/images/tistory/46/3.png)

**예제1 ) ROWNUM으로 순번 붙여주기**

```sql
SELECT ROWNUM, A.*
   FROM EMP A;
```

![](/images/tistory/46/4.png)

**예제2) EMPNO 순서대로 정렬하기**

```sql
SELECT ROWNUM, A.*
   FROM EMP A
ORDER BY EMPNO;
```

> \*참고) 정렬을 하면 아래처럼 순번이 뒤바뀝니다.

![](/images/tistory/46/5.png)

**예제3) inline view를 사용하여 empno로 정렬하여 순번 메기기**

```sql
SELECT ROWNUM, A.*
FROM ( SELECT *
                 FROM EMP
               ORDER BY EMPNO
) A;
```

![](/images/tistory/46/6.png)

**예제4) EMPNO로 정렬하여 순번메긴후, 순번 5개까지만 불러오기**

```sql
SELECT ROWNUM, A.*
FROM (
               SELECT *
                  FROM EMP
                ORDER BY EMPNO
) A
WHERE ROWNUM <= 5;
```

![](/images/tistory/46/7.png)

**예제5) ROWNUM을 별칭 LIST로 불러오고, ENAME을 불러오되, 순번이 5~10까지인 데이터를 조회하라**

```sql
SELECT *
    FROM (
                   SELECT ROWNUM LIST, ENAME
                      FROM EMP
                )
  WHERE LIST BETWEEN 5 AND 10;
```

![](/images/tistory/46/8.png)

> \*참고)
> 
> SQL Sever TOP구문 / MySQL의 limit 구문 / Oracle의 ROWNUM
> 
> \- 오라클은 ROWNUM을 사용하지만 SQL Server에서는 TOP문을 MySQL에서는 LINIT구를 사용합니다.
> 
> 
> 
> \[ ORACLE \]
> 
> SELECT \* FROM EMP WHERE ROWNUM &lt;= 5;
> 
> \[ SQL Server \]
> 
> SELECT TOP(10) FROM EMP;
> 
> \[MySQL\]
> 
> SELECT \* FROM EMP LIMIT 10;
>

> **② ROWID**

**\- ROWID는 오라클 데이터베이스 내에서 데이터를 구분할 수 있는 유일한 값입니다.**

**\- ROWID는 "SELECT ROWID, EMPNO FROM EMP" 와 같은 SELECT문으로 확인할 수 있습니다.**

**\- ROWID를 통해서 데이터가 어떤 데이터 파일, 어느 블록에 저장되어있는지 알 수 잇습니다.**

**\- 주로 테이블에서 특정 레코드를 랜덤하게 접근하기 위해서 사용됩니다.**

**\- ROWID는 오라클에서 INDEX를 생성하기 위하여 내부적으로 사용하는 PSEUDOCOLUMN이므로 사용자가 임의로 변경하거나 삭제할 수 없습니다.**

**\[ROWID 구조\]**

![](/images/tistory/46/9.jpg)

**① 오브젝트번호 : 처음6자리는 오브젝트 번호입니다. Object별로 유일한 값을 가지고 있습니다.**

**② 상대파일번호 : 7~9자리는 테이블스페이스 상대파일 번호입니다. 동일한 테이블의 데이터일지라도 테이블의 익스텐트가 다른 데이터파일에 할당 될 경우, 해당 값은 서로 다르게 할당 될 수 있습니다.**

**③ 블록번호 : 10~15자리는 데이터 팡리 내부에서 어느 블록에 데이터가 있는지 알려줍니다.**

**④ 데이터번호 : 16~18자리는 데이터 블록에 데이터가 저장되어있는 순서를 말합니다.**

**예제) EMP 테이블에서 ROWID를 조회하기**

```sql
SELECT ROWID,ENAME
   FROM EMP;
```
