> **① TCL이란? ( Transaction Control Language )**

\- **TCL은 Transaction Control Language로 트랜잭션을 제어하는 언어**입니다.

\- TCL의 종류로는 작업한 내용을 반영하는 COMMIT, 작업한 내용으로 되돌리는 ROLLBACK이 있습니다.

\- 하나의 트랜잭션에 묶여있는 DML(데이터 조작어)의 수행상태는 모든 명령어가 정상적으로 수행완료된 상태, 또는 모든 명령어가 수행되지않아 취소된 상태 두가지로만 존재할 수 있습니다. 이 두가지 상태중 하나로 유도하는 명령어를 의미합니다.

\- 즉, **데이터 조작을 데이터베이스에 영구적으로 반영하거나 작업전체를 취소하는 언어**입니다.

* * *

> **② 트랜잭션 (Transaction)이란?**

\- **트랜잭션은 데이터베이스에서 데이터를 처리하는 하나의 단위를** 의미합니다.

\- 여러개의 쿼리문을 작성하였을때, 그쿼리문들이 정상적으로 작성되었다면 정상종료(데이터베이스에 반영) 되고, 하나라도 잘못되었다면 모든 명령이 취소되는 ALL-OR-NOTIONG 방식으로 처리됩니다.

\- 트랙잭션과 관련된 자주 사용되는 비유로 현금을 인출하는 과정을 예로 들 수 있습니다.

ATM 기에 현금을 인출하려는 버튼을 클릭후, 카드를 넣고 비밀번호를 입력하면 원하는 금액이 ATM기기에서 인출됩니다.

이러한 하나의 처리과정이 트랜잭션이고, 이때 정상적으로 인출되었다면 인출된 금액만큼 계좌에서 차감이 될것(데이터베이스에 반영) 이고, 부득이한 오류나 잘못된 조작, 정전 등으로 종료될 경우 처음의 상태, 즉 거래가 취소되며 계좌에는 반영이 되지 않습니다.

\- 이러한 **트랜잭션의 개념에 의해 데이터베이스의 일관성을 유지하고 안정적인 복구가 가능**합니다.

> **④ COMMIT**

\- COMMIT은 INSERT, UPDATE, DELETE문으로 변경한 데이터를 데이터베이스에 반영합니다.

\- 변경이전 데이터는 잃어버립니다. 즉 A값을 B로 변경하고 COMMIT을 하면 A값은 잃어버리고 B값을 반영합니다.

\- 다른 모든 데이터베이스 사용자는 변경된 데이터를 볼 수 있습니다.

\- COMMIT이 완료되면 데이터베이스 변경으로 인한 LOCK이 해제 됩니다.

\- COMMIT이 완료되면 다른 모든 데이터베이스 사용자는 변경된 데이터를 조작할 수 있습니다.

\- COMMIT을 실행하면 하나의 트랜잭션 과정이 종료됩니다.

![](/images/tistory/47/3.jpg)

![](/images/tistory/47/4.png)

\> EMP 테이블에서 EMPNO 7900인 데이터의 ENAME을 TALER로 변경한다.

SQL> UPDATE EMP SET ENAME = 'TALER' WHERE EMPNO = 7900; 1 행이 업데이트되었습니다.

\> COMMIT을 실행하여 데이터베이스에 반영한다.

SQL> COMMIT;

커밋이 완료되었습니다.

> \* 참고) Auto Commit
> 
> 
> 
> \- SQL\* PLUS 프로그램을 정상적으로 종료하는 경우, 자동 COMMIT이 됩니다.
> 
> \- DDL 및 DCL을 사용하는 경우 자동 COMMIT이 됩니다.
> 
> \- "SET AUTOCOMMIT ON;"을 SQL\*PLUS에서 실행하면 자동 COMMIT이 됩니다.

> **⑤ ROLLBACK**

\- ROLLBACK을 실행하면 데이터에 대한 변경 내용을 모두 취소하고 트랜잭션을 종료합니다.

\- INSERT, UPDATE, DELETE문의 작업을 모두 취소합니다.

\- 단, 이전에 COMMIT한 곳까지만 복구합니다.

\- ROLLBACK을 실행하면 ROCK이 해제되고 다른 사용자도 데이터베이스 행을 조작할 수 있습니다.

![](/images/tistory/47/5.jpg)

* * *

> **⑥ SAVEPOINT**

\- SAVEPOINT는 트랜잭션을 작게 분할하여 관리하는 것으로 SAVEPOINT를 사용하면 지정된 위치 이후 트랜잭션만 ROLLBACK이 가능합니다.

\- SAVEPOINT의 지정은 SAVEPOINT \[SAVEPOINT명\]을 실행합니다.

\- 지정된 SAVEPOINT까지만 데이터 변경을 취소하고 싶은 경우는 ROLLBACK TO \[SAVEPOINT명\]을 실행하면 됩니다.

\- ROLLBACK을 실행하면 SAVEPOINT와 관계없이 데이터의 모든 변경사항을 저장하지 않습니다.

SQL> SELECT ENAME FROM EMP WHERE EMPNO IN(7499, 7900); -- EMPNO 7499,7900 조회하기

ENAME ----------

JAMES

TALER

SQL> SAVEPOINT T1; -- SAVEPOINT T1

저장점이 생성되었습니다.

SQL> UPDATE EMP SET ENAME ='변경이름1' WHERE EMPNO = 7499;

1 행이 업데이트되었습니다.

SQL> SAVEPOINT T2; -- SAVEPOINT T2

저장점이 생성되었습니다.

SQL> UPDATE EMP SET ENAME='변경이름2' WHERE EMPNO = 7900;

1 행이 업데이트되었습니다.

SQL> ROLLBACK TO T2; -- T2부터 ROLLBACK 롤백이 완료되었습니다.

SQL> SELECT ENAME FROM EMP WHERE EMPNO IN (7499, 7900); -- EMPNO 7499,7900 조회하기

ENAME ----------

변경이름1

TALER
