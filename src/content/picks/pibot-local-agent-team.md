한 줄로 말하면 "위험한 일은 매번 결재를 올리는 **내 책상 위 봇 팀**"이에요. 이름 붙은 봇들이 내 컴퓨터 안에서 명령을 실행하고 파일을 고치고 웹을 보고 컴퓨터를 조작하는데, 위험한 단계마다 내 승인을 기다려요. 한 봇과 바로 대화하거나 여러 봇을 그룹 채팅에 모아 역할을 나눠 일을 서로 넘겨요. 채팅, 파일, 메모리, 키가 모두 내 기기에 남고, 내가 고른 모델 제공자만 보낸 프롬프트를 봐요.

DBA·개발 눈으로 보면 이렇게 써 볼 수 있어요.
- **승인과 감사 로그가 기본**: 모든 도구 호출이 하나의 정책 엔진을 지나고 바깥으로 나간 건 감사 로그에 남아, 운영 작업을 에이전트에 맡겨도 "무엇을 실행했나"를 나중에 되짚을 수 있어요
- **폐쇄망에서도 로컬 모델로**: Ollama나 내 API 키로 모델을 고를 수 있어, 바깥으로 데이터를 보내기 어려운 환경에서도 로컬 모델만으로 돌려 볼 수 있어요
- **역할을 쪼개서 맡기기**: 개발·리서치·작성 같은 역할을 가진 봇을 모아, 스크립트 초안은 한 봇이 쓰고 다른 봇이 점검하는 식으로 나눠 맡길 수 있어요

써 보기 전에 알아둘 것도 있어요. macOS·Windows·Linux 데스크톱 앱이고 안드로이드 앱도 있어요. 단계마다 승인을 받게 돼 있지만 결국 내 컴퓨터를 조작하는 자율 에이전트라, 작업 폴더와 권한은 좁게 잡아 두는 게 안전해요. pi 에이전트 커널을 바탕으로 만들어졌고, 라이선스는 Apache 2.0이에요.
