한 줄로 말하면 "고친 뒤 **같은 맛인지 시식까지 하는** SQL 요리사"예요. 국내 업체 오픈메이드컨설팅이 LLM으로 Oracle에서 도는 SQL을 분석하고 고쳐 주는 쿼리메딕 2.0을 16일에 내놓는대요. 이번 버전은 고친 SQL이 원래와 같은 결과를 내는지 자동으로 비교하고, 실제 운영 환경에서 빨라졌는지까지 확인하는 쪽을 강화했어요.

DBA 눈으로 보면 이런 점이 눈에 들어와요.
- **튜닝 전후 결과 비교**: 힌트를 넣거나 서브쿼리를 조인으로 바꾼 뒤 결과 건수와 값이 같은지 확인하는 일을 자동으로 해 줘서, 가장 손이 많이 가는 검증 단계를 덜 수 있어요
- **인덱스 부작용 점검**: 새 인덱스를 제안할 때 다른 SQL의 실행계획에 미치는 영향까지 본다고 해서, 인덱스 하나 추가했다가 다른 배치가 느려지는 일을 줄일 수 있어요
- **사내 SQL 표준 점검**: 개발 단계에서 회사 SQL 작성 기준에 어긋난 구문을 찾아 고쳐 줘서, 운영에 올라오기 전에 걸러 낼 수 있어요

써 보기 전에 알아둘 것도 있어요. 공개 소프트웨어가 아니라 판매용 제품이고, 기사도 회사 발표를 옮긴 내용이라 실제 성능 수치는 나와 있지 않아요. 지금은 Oracle 대상이고, 수백에서 수천 줄짜리 대형 SQL까지 다룬다고 해요. 운영 SQL과 데이터가 어디에서 처리되는지(사내 설치인지 외부 전송인지)는 도입 전에 꼭 확인해야 해요.
