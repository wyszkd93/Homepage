한 줄로 말하면 "대화 기록을 **한 글자도 줄이지 않는** 고집 센 비서"예요. 화면 없이 터미널 입력과 출력만으로 돌아가는 코딩 에이전트 실행기인데, 긴 대화를 요약하거나 명령 결과를 몰래 잘라 내지 않고 매번 전체를 그대로 모델에 보내요. 파일 읽기, 파일 쓰기, 한 군데 바꾸기, 명령 실행 네 가지 도구만 있는 Go 바이너리 하나라서 서버에 올려 두기도 가벼워요.

DBA 눈으로 보면 이렇게 써 볼 수 있어요.
- **알람 로그 1차 분석**: `cat alert.log | uncut "ORA- 오류를 시간순으로 묶고 원인 후보를 정리해 줘"`처럼 파이프로 넘기면, 중간이 잘린 채 엉뚱한 결론을 내는 일 없이 전체를 보고 답해요
- **배치 스크립트 점검 자동화**: CI나 크론에서 `--json`으로 돌리면 모델이 무엇을 읽고 어떤 명령을 실행했는지가 줄 단위 기록으로 남아서, 나중에 감사 자료로 쓰기 좋아요
- **사내 모델과 연결**: OpenAI 호환 주소만 받으니 사내 Ollama 같은 로컬 모델에 붙여, 쿼리나 설정 파일을 밖으로 내보내지 않고 검토를 맡길 수 있어요

써 보기 전에 알아둘 것도 있어요. 설치는 릴리스에서 OS별 파일 하나를 받으면 끝이고, `UNCUT_MODEL`과 API 키(로컬 모델은 생략 가능)만 정하면 돼요. 다만 샌드박스가 아니라서 모델이 내 계정 권한 그대로 셸 명령을 실행하고, 승인 창도 없어요. 운영 DB 서버에서 바로 돌리지 말고 권한을 좁힌 계정이나 컨테이너에서 쓰는 게 안전해요. 전체 기록을 매번 보내는 만큼 대화가 길어지면 토큰 비용이 빠르게 늘어요. 라이선스는 MIT예요.
