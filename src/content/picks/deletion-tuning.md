한 줄로 말하면 "**군더더기를 덜어 내서** 더 잘하게 만드는 방법"이에요. 뉴욕대와 캘거리대 연구진이 내놓은 '삭제 튜닝'은 모델 가중치를 새로 수정하지 않고, 전체의 0.05%도 안 되는 가중치만 골라 0으로 꺼요. 그것만으로 수학 추론과 도구 사용 능력이 크게 올라, 전체를 다시 학습하는 방식과 맞먹거나 조금 앞섰대요. 예를 들어 라마 8B의 수학 평가 점수가 60%대에서 83%대로 뛰었어요.

DBA 눈으로 보면 이런 점이 눈에 들어와요.
- **학습 결과가 작아짐**: 전체 미세조정 결과는 수십 GB인데, 삭제 튜닝은 '어떤 가중치를 끌지'만 기록해서 8MB 수준이에요. 사내 모델을 작업별로 여러 벌 보관할 때 저장 부담이 확 줄어요
- **원래 능력을 덜 잃음**: 특정 작업에 맞추면 기존 실력이 깎이는 일이 흔한데, 값을 고치지 않고 끄기만 해서 기존 능력을 더 잘 지킨대요
- **아직은 연구 단계**: 바로 쓰는 제품이 아니라 논문(NeurIPS 2026 채택) 결과예요. 사내 모델 튜닝 방식을 고를 때 참고할 흐름으로 보면 돼요

써 보기 전에 알아둘 것도 있어요. 기본 모델은 따로 보관해야 하고, 경량 미세조정으로 이미 쓰이는 로라와 비교하면 저장 용량 이점은 상대적으로 작아요. 실험은 라마, 큐원 같은 공개 모델에서 수학과 도구 사용 위주로 확인한 것이라, 우리 업무 같은 다른 작업에서도 같은 효과가 날지는 더 봐야 해요. 논문과 그림은 arXiv에 공개됐어요.
