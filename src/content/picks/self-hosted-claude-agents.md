한 줄로 말하면 "에이전트의 **작업장뿐 아니라 관제실까지** 사내로 들여놓는 선택지"예요. 전에도 에이전트가 코드를 실행하는 샌드박스는 사내 서버에 둘 수 있었지만, 작업을 지시하고 진행을 관리하는 핵심 시스템은 Anthropic이 운영했어요. 이번 '자체 호스팅 클로드 관리형 에이전트'는 관리 서버, 데이터베이스, 실행 환경, 인증 정보까지 기업이 직접 운영하게 범위를 넓혔어요. 모델 자체를 설치하는 건 아니고, 추론은 여전히 Anthropic이나 베드록·구글 클라우드 등을 거쳐요.

DBA 눈으로 보면 이런 점이 눈에 들어와요.
- **에이전트 기록을 사내 DB에**: 에이전트가 무슨 시스템에 접근해 어떤 작업을 했는지가 사내 데이터베이스에 남아서, 감사나 사고 추적 때 밖에 묻지 않고 직접 볼 수 있어요
- **인증 정보를 안 내보냄**: DB 접속 계정이나 키 같은 민감 정보를 사내 환경에서만 관리하고, 에이전트가 닿을 네트워크를 좁힐 수 있어요
- **접근 통제의 눈높이**: "이 에이전트는 읽기 전용 복제본까지만" 같은 통제를, 외부 서비스 설정이 아니라 우리 인프라에서 걸 수 있어요

써 보기 전에 알아둘 것도 있어요. 지금은 신청해야 쓸 수 있는 비공개 베타예요. 관리 시스템은 사내에 두더라도 추론 요청과 작업 결과는 선택한 모델 제공업체로 나가니, 그 경로에 어떤 데이터가 실리는지는 따로 확인해야 해요. 모델을 통째로 사내에 설치하는 방식이 필요하면 이건 답이 아니에요.
