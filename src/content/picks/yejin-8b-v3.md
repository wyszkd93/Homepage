한 줄로 말하면 "남의 집을 고쳐 쓴 게 아니라 **터부터 직접 다진** 한국어 집"이에요. AI 회사 예진이 해외 공개 모델의 가중치를 빌리지 않고 토크나이저 설계부터 사전학습까지 직접 한 80억 매개변수 한국어 모델을 내놨어요. 모델 파일이 15GB 정도라 공공기관 내부망이나 기업 전산실 서버에서도 돌릴 수 있고, 같은 한국어 법령 문서를 해외 모델보다 24~38% 적은 토큰으로 처리한대요.

DBA 눈으로 보면 이렇게 써 볼 수 있어요.
- **망 분리 환경의 사내 도우미**: 인터넷이 막힌 운영망 안에서 내부 매뉴얼이나 작업 절차서를 찾아 주는 검색 도우미의 바탕 모델로 쓸 만한 크기예요
- **한국어 문서 요약과 정리**: 작업 계획서, 장애 보고서, 변경 요청서 같은 한국어 문서를 요약하거나 양식에 맞춰 다듬는 일에 맞아요
- **숫자에 강한 토크나이저**: 숫자를 따로 쪼개 처리해서, 수치가 많은 점검 결과나 용량 보고서를 다룰 때 토큰을 아낄 수 있어요

써 보기 전에 알아둘 것도 있어요. 8B급이라 복잡한 SQL 작성이나 긴 추론은 대형 모델보다 약할 수 있으니, 요약과 검색 보조처럼 가벼운 일부터 맡기는 게 좋아요. 성능 비교는 30B 이하 중소형 모델 순위 기준이에요. 라이선스는 상업적 이용과 수정이 자유로운 Apache 2.0이고, 데이터를 2.5배 늘린 v4를 연내 공개할 계획이래요.
