한 줄로 말하면 "더 똑똑해졌는데 **식비는 줄어든** 신입"이에요. Anthropic이 최상위 모델 Claude Fable 5.2를 내놨는데, 외부 종합 평가에서 구글 모델을 제치고 다시 1위에 올랐고 API 가격은 20% 내렸어요. 이전 5.1보다 코딩, 추론, 과학 연구 능력을 끌어올렸고 출력 속도도 최대 30% 빨라졌대요. 같은 바탕 모델에서 보안과 생물학 제한을 일부 푼 Mythos 5.2는 검증된 기관에만 제공해요.

DBA 눈으로 보면 이런 변화가 기대돼요.
- **실제 코드 고치기 실력**: 오픈소스 프로젝트 코드를 고치는 평가에서 크게 올라서, 오래된 PL/SQL 패키지 리팩터링이나 마이그레이션 스크립트 수정을 맡길 때 덜 헤맬 수 있어요
- **같은 답을 더 적은 토큰으로**: 높은 추론 설정에서도 이전 최상위 모델보다 출력 토큰을 40%쯤 덜 써서, AWR 분석처럼 긴 자료를 자주 넣는 작업의 비용이 줄어요
- **지식 업무 평가 두 배**: 문서 정리, 보고서 작성 같은 실제 업무 평가 점수가 이전 버전의 두 배를 넘어서, 장애 보고서 초안 같은 일에도 더 쓸 만해졌어요
