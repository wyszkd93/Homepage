한 줄로 말하면 "곁에서 어깨너머로 배우다가 내가 자리를 비우면 **혼자 복습하는 견습생**"이에요. 로컬 모델을 opencode나 pi 같은 OpenAI 호환 도구로 평소처럼 쓰면, Songe가 모델의 행동 뒤에 따라오는 것들 — 도구 실행 결과, 에러, 내 다음 말 — 을 지켜봐요. 그러다 에이전트가 한가해지면 그 장면들을 가지고 모델이 다음을 미리 내다보도록 가르쳐요. 새로 길러진 버전은 내 실제 대화에서 더 나을 때만 채택되고, 아니면 한 번에 이전으로 되돌려요.

DBA·개발 눈으로 보면 이렇게 써 볼 수 있어요.
- **우리 팀 방식을 몸에 배게**: 폐쇄망에서 쓰는 로컬 코딩 모델이 우리 SQL 컨벤션이나 자주 나는 오류를 스스로 익혀, 매번 프롬프트로 일러 주지 않아도 되게 길들여요
- **밖으로 안 나가는 학습**: 운영 로그나 쿼리를 외부 API로 보내지 않고 내 PC 안에서만 학습해, 데이터 반출이 막힌 환경에서도 모델을 다듬을 수 있어요
- **되돌릴 수 있는 교체**: 새 버전이 내 대화에서 실제로 더 나을 때만 쓰고 한 번에 롤백돼서, 운영 도구를 바꿀 때처럼 신중하게 올릴 수 있어요

써 보기 전에 알아둘 것도 있어요. 로컬 모델을 OpenAI 호환 도구로 쓰는 걸 전제로 하고, 설치는 `uv tool install songe`나 `pipx install songe`(Python 3.11 이상)예요. 에이전트가 조용하고 메모리·배터리에 여유가 있을 때만 백그라운드로 돌고 내가 돌아오면 멈춰요. 계정도 텔레메트리도 클라우드도 없이 전부 내 기기 안에서 돌아가며, 라이선스는 Apache 2.0이에요.
